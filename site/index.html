Crie o seu widget

Uma pasta com um manifest.json e um script em qualquer linguagem. O que o script escreve aparece no dock.

Nas Configurações › Widgets › Widgets personalizados: criar a partir de um modelo, exportar um arquivo .gprwidget e instalar o de outra pessoa. Ao salvar o script, o dock recarrega o widget sozinho.

Ler o guia completo

#!/bin/bash
# widget.sh: roda a cada "interval" segundos
valor=$(curl -fsS https://economia.awesomeapi.com.br/json/last/USD-BRL \
        | jq -r '.USDBRL.bid')
printf 'R$ %.2f\n' "$valor"     # o valor em destaque
echo "Dólar comercial"          # a legenda
echo "Atualizado às $(date +%H:%M)"  # o painel do clique

Precisa de mais? Escreva um JSON para ter anel de progresso, alerta e linhas clicáveis, ou um módulo JavaScript com a mesma API dos widgets que vêm no dock.

Instalar

Para Ubuntu com GNOME Shell 50 (Wayland). As atualizações chegam junto com as do sistema.

curl -fsSL https://gustavoreimche.github.io/gprdock/gprdock.gpg | sudo tee /usr/share/keyrings/gprdock.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/gprdock.gpg] https://gustavoreimche.github.io/gprdock stable main" | sudo tee /etc/apt/sources.list.d/gprdock.list
sudo apt update && sudo apt install gprdock

Depois saia e entre na sessão e ative a extensão:

gnome-extensions enable gprdock@gpr

Prefere o arquivo? O .deb de cada versão está em Releases.
